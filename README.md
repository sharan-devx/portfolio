# Portfolio: Koona Sharan Kumar

React + Vite portfolio. Run locally: `npm install` then `npm run dev`.

## Add your screenshots
Put two images in `public/screenshots/` named exactly `urbanweave.png` and `inkwell.png`
(a screenshot of each home page works well). Until then, a colored letter card is shown.

## Deploy
Push to GitHub, then on vercel.com choose Add New, Project, import this repo, and click Deploy.
